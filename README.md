# facaraff.github.io

Academic website of Fabio Caraffini, built with [al-folio](https://github.com/alshedivat/al-folio) (Jekyll) and hosted on GitHub Pages at https://facaraff.github.io.

## How it works

- Edit files on the `master` branch. The "Deploy site" GitHub Action builds the site into `gh-pages`, which GitHub Pages serves. Never edit `gh-pages`.
- Pages are in `_pages/`, structured data in `_data/`, publications in `_bibliography/papers.bib`, files such as the CV PDF in `assets/`.
- See [MAINTENANCE.md](MAINTENANCE.md) for how to add a publication, project, student, talk or social link, and how to replace the CV.
